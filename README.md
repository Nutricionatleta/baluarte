# Baluarte — juego personal de Pablo

Juego de estrategia medieval para el móvil. **No tiene nada que ver con el negocio
ni con `pablo-workspace`.** Vive solo en esta carpeta.

## Cómo se juega
1. `npm install` (solo la primera vez)
2. `npm run dev`
3. Abre en el móvil la dirección `http://<ip-del-pc>:5180` estando en el mismo wifi.
   (Más adelante se puede publicar gratis para jugar desde cualquier sitio.)

## Cómo se borra
Borra esta carpeta entera. Ya está. No instala nada fuera de aquí, no crea
servicios, no toca el registro de Windows y no deja ficheros sueltos por el disco.
La partida guardada vive en el navegador del móvil: se borra desde
Ajustes → Borrar partida, o limpiando los datos del sitio.

## Coste
**0 €.** Sin servidores, sin base de datos, sin APIs de pago, sin assets de pago.
Todo el 3D se genera por código y la partida se guarda en el propio móvil.
